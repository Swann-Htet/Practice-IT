# IT07 Practice

Multiple-choice practice site for the Exit Exam IT07 (IT Literacy) answer sheet.

- 207 questions in 3 parts, taken word-for-word from the sheet
- Correct answers follow the sheet; wrong options are written for practice
- Picture questions show the matching PDF page
- Single file: open `index.html` in a browser (font: DM Sans, loaded from Google Fonts)

Known gaps: Part 1 Q71 has no answer in the sheet, and Part 3 Q56-58 are picture-only questions.
