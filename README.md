# IT07 Practice

Exit Exam (IT Literacy) multiple-choice practice site, built for the MFU IT07 sheet.

- **LMS set** - 60 lecturer-given questions (questions marked "Missed before" are the ones answered wrong earlier)
- **Practice bank** - 207 questions from the Exit Exam IT07 sheet, copied word-for-word
- Practice mode (instant feedback) and Exam mode (answers at the end), question palette, timer
- Answers, marks and timer are saved in the browser, so a refresh keeps your progress

Open `index.html` through any static server (or GitHub Pages). Data is in `data/questions.js`, pictures in `Assets/`.
